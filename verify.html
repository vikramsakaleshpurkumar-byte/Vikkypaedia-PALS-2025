What it says

Read this before you rely on it. A completion record is self-attested. It is produced on the learner’s own device from data held in their browser, and the checksum is a plain hash computed by code that ships inside the module — anyone with the file can recompute it. So a matching checksum tells you the record has not been casually altered, mistyped or truncated in transit. It does not prove the learner sat the assessment, and it is not evidence issued by a third party. If you need records you can rely on for promotion, credentialling or audit, you need a server-side system with authenticated sign-in, not this.
